# jbl-wan-proof

**Краткий путеводитель по проекту · EN / RU**

Закрытый репозиторий доказательных материалов под управлением владельца. Метаданные описывают проверку доступности через WAN с разрешения владельца; в проверенном снимке исходная README отсутствовала. Этот путеводитель не подтверждает независимо наличие доступности и не присваивает степень серьёзности.

Используйте зафиксированный коммит и исходные файлы в пределах прав репозитория. Путеводитель добавляет маршрут чтения и не включает полезные нагрузки, учётные данные или содержимое закрытых доказательств.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.

Закрытый репозиторий: доступ сохраняется только для уполномоченных читателей.

В проверенном коммите README.md отсутствовала; поэтому ссылка на снимок открывает зафиксированное дерево файлов.
